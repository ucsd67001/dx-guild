# Yokoten（横展）

> チームの工夫を、横へ広げる。

IT Div. の中で、**困りごと**（手作業・時間を取られていること）と、
**解決策**（ノーコード・ローコード・AI エージェントでこう解いた）を共有し、
よそのチームへ**横展開**するためのコミュニティ。

いまは**ローカルで動かす試作**（v0.1）。ログインは無く、右上で「だれとして使うか」を選ぶ。

---

## なぜ作るか

- 困りごとと解決策が、グループ・チームの中に閉じている
- 別のチームが、同じことを別々にやっている（同じ困りごと、同じ仕組みの作り直し）
- うまくいった工夫が、ほかのチームへ広がらない

→ 「同じことで困っているチーム」と「もう解いたチーム」を見えるようにして、つなぐ。

## できること（v0.1）

| 画面 | 中身 |
|---|---|
| ホーム `/` | 横展開マップ（チームのあいだで解決策が渡った向き）・数字（困りごと／解決策／横展開／減った時間）・解決策を待っている困りごと・いま広がっている解決策・新着 |
| 探す `/explore` | 種類（困りごと／解決策／解決策待ち）・キーワード・分類・ツール・チームで絞り込み、新しい順／反響順／時間の大きい順 |
| 投稿の詳細 `/posts/[id]` | **困りごと**：「うちも困っている」・この困りごとへの解決策・解決策を投稿する ／ **解決策**：「うちでも使いたい」・「〇〇チームに横展開した」（ひとことつき）・取り入れたチームの一覧 ／ 共通：コメント・**似ている投稿**（タグ・ツール・分類が重なる、よそのチームの投稿） |
| 投稿する `/new` | 困りごとと解決策を一つのフォームで。解決策は「答えている困りごと」につなげられる |
| チーム `/teams` | 横展開マップ（大）と、チームごとの数（困りごと・解決策・広げた・取り入れた） |
| チームの頁 `/teams/[id]` | メンバー・そのチームの解決策と困りごと・よそから取り入れた解決策 |

## 動かし方

Node.js 22 以上。リポジトリの一番上で：

```powershell
npm install
npm run dev
```

http://localhost:3000 を開く。

- DB は `data/yokoten.db`（SQLite・git に入れない）。**初めて開いたときに、見本データで作られる**
- 見本データに戻したいとき：開発サーバーを止めてから `npm run db:reset` → もう一度 `npm run dev`
- 確かめ：`npm run typecheck` ／ `npm run lint`

## 作り

| | |
|---|---|
| 画面とサーバー | Next.js 16（App Router・Server Actions）＋ TypeScript |
| DB | SQLite（better-sqlite3）。表の定義は `src/lib/db.ts`、見本データは `src/lib/seed.ts` |
| 見た目 | 手書きの CSS 一枚（`src/app/globals.css`）。頭に考え方を書いてある |

```
src/
  app/            画面（page.tsx がそれぞれの頁）
  components/     札（PostCard）・横展開マップ（FlowMap）・人の切り替え・メニュー
  lib/
    db.ts         DB を開く・表の定義
    seed.ts       見本データ（チームも人も架空）
    data.ts       読み出し（画面から呼ぶ）
    actions.ts    書き込み（投稿・リアクション・横展開・コメント）
    constants.ts  分類・ツール・段階の一覧
```

## 見た目の考え方

- **明るい地**（ごく薄い緑がかった灰色）に、**黒い字**と**緑の差し色**。困りごとは青緑
- 構造は **1px の罫**でつくる。角丸は 2px。浮かせるのは触れたときだけ
- 近未来の手ざわりは、**方眼の地・四隅の目印・等幅の英字の札・線を流れる点**で出す
- 字は IBM Plex Sans JP（和文）と IBM Plex Mono（数字・英字の札）

## 次に考えること

- ログイン（社内に出すなら Entra ID など）。いまの「人の切り替え」は試作のためだけ
- 置き場所（社内のサーバー・Azure など）と、それに合わせた DB（SQLite のままでよいか）
- 解決策の「中身」の受け渡し（フローのパッケージ・プロンプト集などのファイルを添える）
- 通知（自分の困りごとに解決策がついた・自分の解決策が横展開された）
- 似ている投稿の探し方を、AI で意味から探す形にする
