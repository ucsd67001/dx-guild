# 社内ハッカソン 応募文（DXギルド）

## 解決したい業務課題（300文字以内）

IT Div.にも、AIなどデータやデジタル技術の活用に長けた人と、そうでない人がいます。日々の業務に悩みや不安、不満があっても、それを具体的な課題に落とし込み、解決策まで考えるのは簡単ではありません。しかも、同じ悩みを抱える人がどこにどれだけいるのかは見えていません。一方で、自ら解決策を作って試し、成果を上げている人もいますが、その工夫も組織として把握しきれていません。その結果、同じ悩みや同じ仕組みづくりが別々に繰り返され、ひとつの成功がほかに広がらず、成果を量産できていません。悩みを課題と解決策に変え、成功を横展開する仕組みがないことが課題です。

## アイデア概要（500文字以内）

DXギルドは、ひとりの成功をみんなの成果に変える、IT Div.のためのアイデアとソリューションのギルドです。
①事例を探す：困りごとを書くと、ほかのチームの成功事例が見つかります。
②賢者と企画する：事例がなければ、AIの「賢者」と壁打ちします。賢者は答えを押しつけず、質問で掘り下げ、ひとことの悩みを、あるべき姿・問題・課題・解決策に整理した企画書にします。解決策には、使うツール、実現方法、ステップ、リスク、明日からの一歩が付きます。
③効果を数字にする：回数・時間・人数・削減率から、減る時間と金額を自動で試算し、成果からインパクトまでの道筋も示します。
④共有して広げる：企画書はワンクリックでクエストとして共有でき、「うちも困っている」「横展開した」が記録されます。
⑤続けたくなる仕掛け：投稿や横展開が経験値になり、レベル・称号・バッジ・チームのランキングと、困りごとに付く報酬が参加を後押しします。
⑥司令室：管理者は、悩みから成果までの流れ、減った時間と金額、優先して手を打つべき困りごとを一目で把握できます。
