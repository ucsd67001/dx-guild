# 社内ハッカソン 応募文（DXギルド）

## 解決したい業務課題（300文字以内）

IT Div.にも、AIなどデータやデジタル技術の活用に長けた人と、そうでない人がいます。日々の業務に悩みや不安、不満があっても、それを具体的な課題に落とし込み、解決策まで考えるのは簡単ではありません。しかも、同じ悩みを抱える人がどこにどれだけいるのかは見えていません。一方で、自ら解決策を作って試し、成果を上げている人もいますが、その工夫も組織として把握しきれていません。その結果、同じ悩みや同じ仕組みづくりが別々に繰り返され、ひとつの成功がほかに広がらず、成果を量産できていません。悩みを課題と解決策に変え、成功を横展開する仕組みがないことが課題です。

## アイデア概要（500文字以内）

DXギルドは、ひとりの成功をみんなの成果に変える、IT Div.のためのアイデアとソリューションのギルドです。悩み・挑戦・成功事例・横展開を、一か所でつなぎます。
①悩みを出す・探す：困りごとを書くと、ほかのチームの成功事例や挑戦が見つかります。「うちも困っている」で、同じ悩みの人が見えます。
②賢者と企画する：事例がなければ、AIの「賢者」と壁打ちします。賢者は質問で掘り下げ、悩みを、あるべき姿・問題・課題・解決策（ツール・ステップ・リスク）の企画書にし、減る時間と金額も自動で試算します。
③挑戦中から共有する：結果を待たずに共有し、「一緒にやりたい」で仲間を募ります。成功すれば成功事例に、うまくいかなくても「学び」として残ります。
④成功を広げる：成功事例をよそのチームが取り入れると「横展開」として記録され、減った時間が積み上がります。
⑤続けたくなる仕掛け：挑戦・成功・横展開が経験値になり、レベル・バッジ・チームのランキングと、困りごとに付く報酬が参加を後押しします。
⑥司令室：管理者は、悩みから成果までの流れ、減った時間と金額、優先すべき困りごとを一目で把握できます。
